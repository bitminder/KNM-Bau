# KNM Bau GmbH Website

Responsive One-Page-Website für die KNM Bau GmbH in 1220 Wien.

## Inhalte
- Startseite mit Hero-Bereich
- Leistungsübersicht
- Unternehmensvorstellung
- Projektablauf
- WhatsApp-Kontaktformular
- Impressum und Datenschutz
- Responsive Navigation

## Veröffentlichung über GitHub Pages
1. Alle Dateien in den `main`-Branch hochladen.
2. Repository öffnen → **Settings** → **Pages**.
3. Unter **Build and deployment**: `Deploy from a branch`.
4. Branch `main` und Ordner `/root` auswählen.
5. Speichern.

## Vor Veröffentlichung ergänzen
- Firmenbuchnummer
- UID-Nummer
- Firmenbuchgericht
- Gewerbebehörde
- WKO-Fachgruppe
- E-Mail-Adresse
- Echte Projektfotos und genaue Leistungsbereiche
